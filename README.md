# Verilog RTL Design of Sequential Circuits (Task 3)

## 📌 Overview
This repository contains the Verilog HDL implementation and simulation of fundamental sequential circuits completed as part of the **MainCrafts VLSI Design Internship – Task 3**.

The project demonstrates the design, verification, and waveform analysis of basic sequential logic circuits using Verilog HDL.

## 🚀 Implemented Modules

### ✅ D Flip-Flop
- Positive edge-triggered D Flip-Flop
- Stores input data on the rising edge of the clock

### ✅ JK Flip-Flop
- Supports Hold, Reset, Set, and Toggle operations
- Positive edge-triggered implementation

### ✅ 4-bit Register
- Stores 4-bit data
- Updates output on every positive clock edge

### ✅ 4-bit Binary Counter
- Synchronous 4-bit Up Counter
- Reset supported
- Counts from 0 to 15
